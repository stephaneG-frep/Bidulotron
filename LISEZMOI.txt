BIDULOTRON — site généré par NabuSite AI
========================================

Ce dossier contient un site Web statique complet et autonome : aucun
logiciel, aucune base de données et aucun service externe ne sont
nécessaires pour l'afficher.

Contenu
-------
  - index.html : Accueil
  - services/index.html : Services
  - projets/index.html : Projets
  - a-propos/index.html : À propos
  - contact/index.html : Contact
  - css/style.css : mise en forme
  - js/site.js : menu mobile et petits effets (le site reste lisible sans)
  - images/ : 20 fichier(s) d'image utilisés par le site
  - robots.txt, sitemap.xml : indications pour les moteurs de recherche

Adresses sans « .html » : chaque page est dans son dossier (contact/index.html).
Elles fonctionnent chez un hébergeur ; en ouvrant les fichiers directement
sur un ordinateur, utilise le petit serveur local décrit plus bas.

État du site
------------
Adresse publique : https://StephaneG-frep.github.io/Bidulotron/
Formulaire de contact : aucun. Les visiteurs utilisent les liens directs
(téléphone, e-mail, WhatsApp) affichés dans la section Contact.
Contenus « À compléter » : aucun.

Voir le site sur un ordinateur
------------------------------
Ouvrir index.html dans un navigateur fonctionne pour un aperçu rapide.
Pour un rendu identique à la mise en ligne, servir le dossier avec un
petit serveur local, par exemple :  python3 -m http.server 8000
puis ouvrir http://localhost:8000

Mettre le site en ligne
-----------------------
Le plus simple : NabuSite AI → menu ⋮ → « Publier en ligne ».
À la main, déposer TOUT le contenu de ce dossier (pas le dossier lui-même),
avec index.html à la racine :
  - GitHub Pages : créer un dépôt, y envoyer les fichiers, puis Settings →
    Pages → « Deploy from a branch » (branche main, dossier / root).
  - Netlify : app.netlify.com/drop → déposer le dossier.
  - Cloudflare Pages : Workers & Pages → Créer → Pages → Téléverser des
    ressources → déposer le dossier ou son archive ZIP.
  - Hébergement classique (OVH, o2switch, Hostinger…) : envoyer les fichiers
    dans le dossier public (www, public_html ou htdocs) par le gestionnaire
    de fichiers ou par FTP, puis activer HTTPS.

Modifier le site
----------------
Les modifications se font dans l'application NabuSite AI, qui régénère le
site. Une modification faite à la main dans ces fichiers serait perdue au
prochain export.
